# Мебельное место — демоверсия сайта

Откройте `index.html` в браузере или разместите папку на статическом хостинге. Для опубликованной версии используется Sites Worker.

## Содержание

- 6 моделей кухонь с размерами, материалами и ценами из карточки организации.
- Фотографии из карточки салона, изображения серий кухонь из открытых каталогов VIVAT и продавцов, ссылки на первоисточники фото, галерею и отзывы. Изображения серий могут отличаться от комплектации и цвета позиции в прайсе.
- Услуги, режим работы, адрес, телефон и маршрут.
- Форма демозаявки: проверка имени, телефона и согласия, номер заявки, сохранение до 30 заявок в `localStorage` текущего браузера.

Заявка **не отправляется в компанию**. Данные сохраняются только на устройстве посетителя. Для реального приема заявок потребуется сервер, защищенное хранение и согласованный канал уведомления.

Данные сверены по доступной версии [карточки организации](https://yandex.com/maps/org/mebelnoye_mesto/154716893725/) и [справочнику](https://msk.spravker.ru/magaziny-mebeli/metro-dmitrovskaya/) 20 ноября 2026 года. Карточка сама помечает прайс как давно не обновлявшийся. Отзывы на странице представлены в пересказе. Изображения загружаются с серверов Яндекса, VIVAT и продавцов; перед коммерческим использованием необходимо проверить права и, при необходимости, заменить их материалами владельца.
